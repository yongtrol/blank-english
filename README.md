# 빈칸 영어

영어 문장의 빈칸에 들어갈 단어를 맞히는 연습 페이지입니다. 한국어 해석에서 빈칸 단어의 뜻에 밑줄이 쳐져 있어 힌트가 됩니다.

## 실행

설치할 것이 없습니다. `index.html`을 브라우저로 열면 됩니다.

## 기능

- 일상 문장 1000개가 무작위 순서로 나오고, 한 바퀴를 다 돌면 다시 섞습니다.
- **확인**: 답을 채점합니다. 대소문자는 구분하지 않습니다.
- **힌트**: 문장당 2번까지 정답의 앞글자를 보여 줍니다.
- **넘기기**: 정답을 보여 주고 다음 문장으로 넘어갑니다.
- 정답, 넘긴 문장, 연속 정답 수를 셉니다 (새로고침하면 초기화).
- 다크 모드를 지원합니다.

| 키 | 동작 |
|----|------|
| Enter | 확인 / 정답 후 다음 문장 |
| Esc | 넘기기 |

## 빈칸 숙제 (`hw.html`)

선생님이 숙제를 만들어 링크로 보내고, 학생이 풀고 결과를 보내는 페이지입니다. 서버가 없습니다. 숙제 내용은 링크(`#` 뒤)에 압축해서 담깁니다.

1. **선생님**: `hw.html`을 열고 한 줄에 하나씩 `영어 | 한국어 해석`을 입력한 뒤, 미리보기에서 빈칸으로 만들 단어를 누르고 링크를 만듭니다. 작성 중인 내용은 브라우저에 자동 저장됩니다.
   - 링크를 만들 때 해석이 없는 문장은 [MyMemory](https://mymemory.translated.net)로 자동 번역해서 채웁니다 (무료, 하루 약 5,000자).
   - [LanguageTool](https://languagetool.org)로 문법, 철자, 중복 단어를 검사합니다. 문제가 있으면 고칠 때까지 링크가 만들어지지 않습니다. 대문자로 시작하는 단어(이름, 지명)는 철자 검사에서 빠집니다. 뜻이 말이 되는지는 검사하지 않습니다.
   - 검사 서비스에 연결하지 못하면 검사 없이 링크를 만들고 안내를 띄웁니다.
2. **학생**: 링크를 열고 이름을 입력한 뒤 풉니다. 문제마다 한 번씩 답할 수 있습니다.
3. 학생이 **결과 보내기**를 누르면 공유 창이 뜨거나 결과가 복사되고, 그걸 카톡 등으로 선생님께 보냅니다.

링크를 학생에게 보내려면 인터넷에 올려야 합니다 (GitHub Pages, Netlify Drop 등). 내 컴퓨터에서 연 `file://` 링크는 다른 사람이 열 수 없습니다.

## 문장 주제

집·일상, 음식·쇼핑, 여행·교통, 직장·학교, 감정·관계·대화, 건강·날씨·자연, 구동사·관용 표현·전치사, 기술·돈·시간·취미·운동

## 문장 추가하기

`index.html`의 `DATA` 배열에 `[영어, 한국어]` 쌍을 추가합니다. 빈칸으로 만들 단어를 `[ ]`로 감싸고, 한국어에서도 그 뜻에 해당하는 부분을 `[ ]`로 감쌉니다.

```js
["I [missed] the bus this morning.", "나는 오늘 아침 버스를 [놓쳤다]."],
```

- 문장마다 괄호는 영어와 한국어에 하나씩만 씁니다.
- 정답은 철자가 정확히 같아야 맞습니다. `canceled`/`cancelled`처럼 철자가 두 가지인 단어는 빈칸으로 쓰지 않는 게 좋습니다.
- 같은 영어 문장이 두 번 들어가면 콘솔에 경고가 뜹니다.
